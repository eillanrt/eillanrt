ALU Emulation and FSM with FPGA

ALU Circuit

Implemented an 4-bit ALU Circuit with FPGA Cyclone IV, using Verilog as HDL. We utilized breadboard as our development board to deliver the output in a timely manner. Switches acted as inputs and LEDs as outputs.

FSM Pattern Detector

Implemented a simple mealy FSM detector that outputs 1 when the input pattern 1101 is detected. Integrated buttons within the FPGA board were used as the inputs. The output signal then goes to the LED as an output indicator. The main challenge encountered was handling the clock timing signal as the chosen FPGA (Cyclone IV EP4CE6) has a clock speed of 50MHz. Which was way too fast for this specific project.
